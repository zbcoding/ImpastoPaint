# Logos

Each app logo Impasto has shipped, named by the releases that used it.

| File | Releases |
|---|---|
| [impasto-logo-v0.6.0.svg](impasto-logo-v0.6.0.svg) | v0.6.0 onward (current) |
| [impasto-logo-v0.0.1-v0.5.0.svg](impasto-logo-v0.0.1-v0.5.0.svg) | v0.0.1 – v0.5.0 |

When the logo changes, add the new SVG here and close the previous file's release range.

The shipped logo is `Pinta.Resources/icons/hicolor/scalable/apps/com.github.zbcoding.Impasto.svg`;
`site/public/assets/impasto-logo.svg` is a copy. Everything else is rendered from it:

- `Pinta.Resources/icons/hicolor/{16x16,22x22,24x24,32x32,96x96}/apps/com.github.zbcoding.Impasto.png`
- `Impasto/Impasto.ico`, `installer/windows/Impasto.ico`, `xdg/Impasto.ico` (16–256 px)
- `installer/macos/impasto.icns` (128–1024 px)
- `installer/windows/logo.bmp` (64 px installer wizard image)
