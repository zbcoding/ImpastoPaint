# Impasto

[🇬🇧 English](readme.md) · Машинный перевод — исправления приветствуются в виде pull request.

Impasto — приложение для рисования и редактирования изображений для Linux, Windows и macOS.

Impasto отлично подходит для быстрого рисования, правки изображений, обрезки, изменения размера и работы со слоями.
Используйте текстовые инструменты для нанесения текста, инструменты фигур для рисования произвольных линий и инструменты выделения, чтобы копировать и вставлять части слоя изображения.
Ниже приведены снимки экрана.

![Инструмент «Текст» с открытым диалогом настроек интерфейса](docs/screenshots/impasto-text-tool.png)

![Контрольная точка фигуры, удерживаемая на центральной линии холста, с направляющей, отображаемой при перетаскивании](docs/screenshots/impasto-snap-to-grid.png)
Изображение функции: то, что вы перемещаете и рисуете, притягивается к сетке холста, к единицам линейки или к краям и центральным линиям холста.

## Загрузка

Сборки для Linux, Windows и macOS доступны на
[странице релизов](https://github.com/zbcoding/ImpastoPaint/releases/latest). Сборки для Windows и
macOS не подписаны, поэтому SmartScreen и Gatekeeper будут выдавать предупреждения.

Impasto требует GTK 4.18 или новее, и это определяет, что будет работать в Linux:

- **Flatpak** — из [FlatPark](https://flatpark.org/apps/com.github.zbcoding.Impasto/) или со
  страницы релизов. Включает собственный GTK и работает везде, где работает flatpak, в том числе в Ubuntu 22.04
  и 24.04. Именно этот вариант стоит выбрать, если вы не уверены.
- **AppImage** (`Impasto-x86_64.AppImage`). Содержит GTK в комплекте, поэтому системный GTK не нужен, но
  сборка собрана под **glibc 2.43** и не запустится на более старых версиях. Это значит, что
  Ubuntu 26.04, Fedora 44 и Arch работают, а Ubuntu 24.04, Ubuntu 22.04, Fedora 43 и Debian 13
  — нет; для них используйте Flatpak.
- **Zip** (`Impasto-linux-dotnet-*.zip`). Использует GTK, предоставляемый вашим дистрибутивом, поэтому требуется
  уже установленный GTK 4.18+.

Impasto распространяется по лицензии MIT (см. `license-mit.txt`). Упоминания сторонних
компонентов, уведомления и тексты лицензий находятся в `THIRD-PARTY-NOTICES.md`.

## Связь с Pinta

Impasto — новый и самостоятельный проект. Он начался с исходного кода
[Pinta](https://github.com/PintaProject/Pinta) под лицензией MIT — приложения на GTK, которое само вдохновлено
[Paint.NET™](https://www.getpaint.net/)
Участники разработки Pinta перечислены в приложении Impasto.
Impasto не поддерживается проектом Pinta или теми же участниками.

<details>
<summary><h2>Сборка в Windows</h2></summary>

Сначала установите необходимые зависимости, связанные с GTK:
- Установите [MSYS2](https://www.msys2.org)
- В терминале CLANG64 выполните `pacman -S mingw-w64-clang-x86_64-libadwaita mingw-w64-clang-x86_64-webp-pixbuf-loader`.
  - Для Windows на ARM64 используйте терминал `CLANGARM64` и замените `clang-x86_64` на `clang-aarch64`.

После этого приложение можно собрать, открыв `Pinta.sln` в [Visual Studio](https://visualstudio.microsoft.com/).
Убедитесь, что .NET 10 установлен через установщик Visual Studio.

Для сборки из командной строки:
- [Установите .NET 10 SDK](https://dotnet.microsoft.com/).
- Сборка:
  - `dotnet build`
- Запуск:
  - `dotnet run --project Impasto`

</details>

<details>
<summary><h2>Сборка в macOS</h2></summary>

- Установите .NET 10 и GTK4
  - `brew install dotnet-sdk libadwaita adwaita-icon-theme gettext webp-pixbuf-loader`
  - Для Apple Silicon задайте в окружении `DYLD_LIBRARY_PATH=/opt/homebrew/lib`, чтобы приложение могло загрузить библиотеки GTK
  - Для Intel задайте в окружении `DYLD_LIBRARY_PATH=/usr/local/lib`, чтобы приложение могло загрузить библиотеки GTK
- Сборка:
  - `dotnet build`
- Запуск:
  - `dotnet run --project Impasto`

</details>

<details>
<summary><h2>Сборка в Linux</h2></summary>

- Установите [.NET 10](https://dotnet.microsoft.com/), следуя инструкциям для вашего дистрибутива Linux.
- Установите остальные зависимости (инструкции даны для Ubuntu 22.10, но для других дистрибутивов они должны быть похожими):
  - `sudo apt install autotools-dev autoconf-archive gettext intltool libadwaita-1-dev`
  - Минимальные версии библиотек: `gtk` >= 4.18 и `libadwaita` >= 1.8
  - Необязательные зависимости: `webp-pixbuf-loader`
- Сборка (вариант 1, для разработки и тестирования):
  - `dotnet build`
  - `dotnet run --project Impasto`
- Сборка (вариант 2, для установки):
  - `./autogen.sh`
    - При сборке из архива с исходным кодом выполните вместо этого `./configure`.
    - Добавьте аргумент `--prefix=<install directory>`, чтобы установить в каталог, отличный от `/usr/local`.
  - `make install`

</details>

## Помощь и участие в проекте:

Мы рады вашему участию. Кратко:

- **Код** — быстрее всего помочь можно, создав issue с описанием своего предложения
  или запроса. Приложите фрагменты кода, имена файлов и контекст.
  Также можно отправить PR. Вклад, полученный в виде PR в бесплатную редакцию,
  может также использоваться в Premium-редакции Impasto или в любом другом программном обеспечении под лицензией MIT.
- **Инструменты ИИ для написания кода** — приветствуются. Будьте готовы объяснить отправляемый код и
  адаптировать его к архитектуре проекта; код, написанный с помощью ИИ, может проходить
  дополнительную проверку перед слиянием.
- **Переводы** — присылайте в виде pull request: черновик, созданный ИИ, в новых файлах `.po`,
  затем отредактированный и вычитанный носителем языка.

Перед тем как внести вклад, прочитайте полное руководство, включая рабочий процесс git/PR, в `CONTRIBUTING.md`.

- Вы можете сообщать об [ошибках и проблемах](https://github.com/zbcoding/ImpastoPaint/issues).
- Значимые изменения каждого релиза фиксируются в `CHANGELOG.md`.
